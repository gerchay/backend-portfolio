# Modern Developer Portfolio

A clean, responsive, and eye-friendly developer portfolio website built with HTML, CSS, and JavaScript.

## Features

- 💜 Purple-themed dark mode design that's easy on the eyes
- 📱 Fully responsive layout (mobile, tablet, desktop)
- 🧩 Modular CSS with clean separation of concerns
- ⚡ No frameworks - pure HTML, CSS, and JavaScript
- 🔄 Dynamic content loading for portfolio and blog sections
- 🏗️ Structured for easy maintenance and future scaling

## Project Structure

```
portfolio/
├── index.html                # Main HTML page
├── /assets/
│   ├── images/               # Profile picture, icons, screenshots
│   └── fonts/                # Web fonts if needed
├── /css/
│   ├── style.css             # General styles
│   ├── layout.css            # Grid, flex, spacing
│   ├── colors.css            # Theme variables and color palette
│   └── components.css        # Cards, buttons, nav, form styling
├── /js/
│   ├── main.js               # Scroll, form, interactivity
│   ├── portfolio.js          # Populate portfolio section dynamically
│   └── blog.js               # Load blog articles
└── /data/
    ├── portfolio.json        # Project info for dynamic rendering
    └── blog.json             # Blog article data
```

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser
3. No build steps or dependencies required!

## Customizing

### Colors

Edit the CSS variables in `css/colors.css` to change the color scheme.

### Content

- Update your personal information in `index.html`
- Add your projects to `data/portfolio.json`
- Add your blog posts to `data/blog.json`
- Replace placeholder images in `assets/images/`

## Browser Support

This project works in all modern browsers (Chrome, Firefox, Safari, Edge).
